## MongoDB Atlas: Automated Embedding
Source: https://www.mongodb.com/docs/vector-search/about/automated-embedding/. A GA announcement also exists: https://www.mongodb.com/products/updates/now-ga-automated-embedding-in-atlas-vector-search/
- Atlas generates embeddings for a **text field** at index time, and for the query string at query time, using a Voyage model.
- **Text only.** The field type must be `text`. No images. That is why our design embeds the **Gemini-written captions**.
- Models: `voyage-3-large`, `voyage-3.5` (our default), `voyage-3.5-lite`.
- Index definition:
  ```json
  { "fields": [ { "type": "text", "path": "caption", "model": "voyage-3.5" },
                { "type": "filter", "path": "hike_id" }, { "type": "filter", "path": "kind" } ] }
  ```
- Query with `$vectorSearch` and a natural-language `query` string, not a vector. Raw vectors can't be passed for an auto-embedded field.
  ```js
  { $vectorSearch: { index: "...", path: "caption", query: "fox sightings", numCandidates: 200, limit: 10 } }
  ```
- **Requires an M10 or higher cluster.** M0 and Flex are presumably unsupported. The $100 credit covers an M10 for the weekend.
- The Atlas UI **can't run vector queries**. Use mongosh or a driver. For the demo video, show the search through our app or mongosh.
- Drivers: Python (pymongo) 4.7+, Node 6.6+. Managing indexes needs the Project Data Access Admin role.
- The docs page had **preview warnings**: datasets under 100k documents, evaluation use only. Not an issue at hackathon scale.
- Embedding inference runs on Google Cloud. Rate limits are global. On HTTP 409, back off and retry.
- **Unverified:** the exact hybrid search syntax (`$rankFusion` combining `$vectorSearch` with `$search`). Confirm at the MongoDB workshop (Fri 15:30).

## Voyage multimodal
Source: https://www.mongodb.com/products/updates/now-available-voyage-multimodal-3-5/
- `voyage-multimodal-3.5` embeds text, interleaved text and images, and video frames. Dimensions are flexible.
- It is accessed with a **separate Voyage API key**. New accounts get 200M free tokens and 150B pixels.
- **Unverified:** whether it works through Atlas Automated Embedding. Probably not, since that is text-only. For image-to-image search (a Could item), embed manually and use a normal vector index.

## BirdNET (bird audio ID)
Source: birdnetlib, https://github.com/joeweiss/birdnetlib
- Python 3.9+. Needs TFLite or TensorFlow, librosa and **ffmpeg** installed first, then `pip install birdnetlib`.
  ```python
  from birdnetlib import Recording
  from birdnetlib.analyzer import Analyzer
  from datetime import datetime
  analyzer = Analyzer()
  rec = Recording(analyzer, "clip.mp3", lat=51.5, lon=-0.1, date=datetime(2026, 10, 1), min_conf=0.25)
  rec.analyze()
  rec.detections  # [{'common_name','scientific_name','confidence','start_time','end_time','label'}]
  ```
- `RecordingFileObject` and `RecordingBuffer` analyse in-memory uploads.
- **Risk:** TFLite installs can be painful, especially on Windows. Time-box it to 1 hour on Friday night. Fallback: Gemini audio analysis plus the GBIF check.

## Strava exports (for friends' data)
Sources: https://takeoutday.org/guides/how-to-export-strava-data, https://help.trainingpeaks.com/hc/en-us/articles/204070254-How-do-I-migrate-my-workout-data-from-Str
- Per-activity export is **web only** (strava.com, open the activity, ⋯ menu). The phone app can't export.
  - **Export GPX:** regenerated by Strava from its own data. GPS track and times. Per TrainingPeaks, **no heart rate**.
  - **Export Original:** the file as uploaded from the device, usually **FIT, with heart rate**. The URL shortcut is `<activity URL>/export_original`. TCX is at `/export_tcx`.
- Bulk export: Settings → My Account → "Download your account" → Request. An email arrives within hours. The `activities/` folder mixes FIT, `.fit.gz` and GPX. `activities.csv` has no GPS. Whether photos are included is unconfirmed.
- **Unverified:** the original file format for Apple Watch workouts synced into Strava. The backend should parse both GPX (`gpxpy`) and FIT (`fitdecode`), and handle `.gz`.

## Photos and EXIF
- Photos sent through standard WhatsApp lose EXIF data (time, GPS) to compression and stripping. Ask for originals via AirDrop, a Drive or iCloud link, or WhatsApp "Document" mode. (General knowledge, not re-verified.)
- With original EXIF time plus GPX timestamps, photos without GPS can be placed on the track (plan item S2). Watch for timezone offsets: EXIF times are local, GPX times are UTC.

## External data APIs (general knowledge, not yet tested in a session)
- **Open-Meteo:** free, no key. Forecast up to about 16 days; daily `sunrise`/`sunset`; separate elevation API. Beyond the forecast window, use the climate or historical APIs and flag the result as an estimate.
- **GBIF:** species name match `https://api.gbif.org/v1/species/match?name=...`; occurrence search `https://api.gbif.org/v1/occurrence/search?taxonKey=...&decimalLatitude=a,b&decimalLongitude=c,d&month=m` (use `count` as the nearby-records signal). Confirm parameters when building.
- **Closures and hazards (UK):** no unified API. Use grounded search or `deep-research-preview-04-2026`, with every claim cited and its check time stored. Example sources: National Trails, National Trust, Natural England (open access restrictions), land managers, MoD firing times where relevant (e.g. Dartmoor).
- **Naismith's rule:** 5 km/h on the flat plus 1 hour per 600 m of ascent. Adjust with the hiker's past pace when history exists.
