# docs/

Planning docs for the Hiking Buddy hackathon project. All except the rubric digest are a **read-only mirror** of the team's Claude Project "Encode Club Hackathon"; edit them there, not here.

| File | What it holds |
|---|---|
| `00-start-here.md` | Status, repo, team, conventions, open items, log. Read first. |
| `hiking-buddy-plan.md` | Scope (Must/Should/Could/Won't), architecture, data model, demo script, timeline, risks, submission checklist |
| `build-spec.md` | Repo layout, service interfaces, API contract, work packages WP0–WP11, AGENTS.md content, overnight prompt template |
| `antigravity-setup.md` | Antigravity setup: quota, permissions, rules, MCP, the check skills |
| `encode-london-2026-context.md` | Hackathon rules, schedule, challenge briefs, Gemini 4 Argon API rules |
| `research-notes.md` | Verified technical facts and what is still unverified |
| `hackathon-spec.md` | Judging rubric digest for coding agents (repo-native) |

Notes on the mirror:
- `friend-outreach.md` (the friend data and consent tracker) is **not** mirrored: it holds third parties' details and stays in the Claude Project.
- The experienced friend's first name is shown as `[friend]` until she has agreed to be named.
- Paths like `claude/build-spec.md` are rewritten to `docs/build-spec.md`.
- Other docs in this folder (`MODELS.md`) are repo-native and editable.
